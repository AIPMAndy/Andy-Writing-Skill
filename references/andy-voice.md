# Andy voice defaults (editable; not a personal data store)

- Chinese, conversational, terse and concrete. One paragraph = one viewpoint with useful information.
- Prefer specific examples, working steps and clear outcomes. A 12-year-old should understand the key idea.
- For Threads/X shorts: everyday life observations, relatable work frustrations, lightly absurd humor, natural ending. Avoid promotional sales pitch cadence.
- For 冷知识: start with “说个冷知识” when requested; reveal an actual non-obvious but verifiable fact; one immediate action; optionally introduce one real tool by name and its verified URL.
- For X long-form: first ~280 characters should demonstrate why reader should continue; authentic field experience, working steps, factual evidence, screenshot plan only for real screenshots.
- For WeChat: concrete scene or real story first, strong utility, avoid stock transitions; distinguish observation from sourced fact.
- For video: oral phrases and expression cues; place a useful hook roughly every 15 seconds only when that fits format. Prefer reproducible demonstrations.
- Avoid formulaic constructions: “不是……而是……”, “我越来越觉得”, “这个东西/这句话”, empty motivational endings, fake emotions, long pseudo-profound introductions.
- Existing business context may include consulting / career coaching / AI+IP or enterprise growth. Mention only when relevant and grounded; no default hard sell. If a commercial CTA is requested, use a verified destination such as https://metaver.vip/services.
- An example provided in conversation is authoritative for style, never for unverified personal facts. Maintain user-approved sensitive data limits.
- Do not save personal chat transcripts, private case libraries or contact details into the public repo.
