# 公众号商单执行覆盖规则（router 专用）

独立 Skill：`agent-skills/andy-wechat-sponsor/SKILL.md`。读取本仓库已内置的商单独立规则与参考文档，**不要把任何未经验证的原帖月收入或外部创作者方法当成 Andy 的亲身经验**。

当与普通公众号长文规范冲突时：
1. 法律、广告披露、真实证据和合同边界优先于任何文体或营销表达。
2. 品牌实测记录和证据不足时，交“选题、待证据清单、沟通模板”，不产虚构亲测稿。
3. 叙事节奏与语言仍由固定的 `khazix-writer` 主笔，`human-writing` 做审稿，不叠加多个风格覆盖；商单必要章节按用户需求更短。
4. 默认不把 Andy 官网、微信、开源项目插入客户广告；用户明确要求且相关、合同允许时最多一个行动入口。
5. 商单任何“广告/商业合作”披露不能用“自然软植入”来隐藏；详见商单目录合规参考文档。
6. 完整交付顺序：品牌评估 → 商务谈判 → 选题 → 素材实证 → 草稿 → 人工确认 → 版式预览 → 授权发布 → 数据复盘。
