# 场景：选题规划 / 内容日历 / 流量复盘

主参考 `content-strategy`，批量内容再参考 CopyFlow。

- 先区分数据事实、用户反馈与假设。不给“必爆”预测。
- 若有真实帖子数据，按平台、日期、曝光、点赞、回复、分享、收藏、关注、咨询分开核对。
- 建选题库：受众生活痛点 → 具体事实 → 可以马上试的方法 → 对应项目/服务（可选）。
- 分别设计纯增长帖和精准转化帖，不把销售内容伪装成亲测故事。
- 输出清晰的测试计划和指标；不能用内容得分冒充增长预测。
- 可按需要把单条主题再交给 threads、x-short、wechat 或 video-script 场景生成。
