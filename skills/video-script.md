# 场景：短视频口播 / 提词器脚本

主写作参考 `IPClaw-Speech`。

- 先确定观众和一句话利益：看完能学到什么、拿到什么。
- 按用户需要输出 30s、60s 或 4–5 分钟口播稿；每隔约 15s 设置一个真正有新信息的注意力点（适用于长视频）。
- 一行一句，句子自然、适合说出口；具体操作步骤先于长篇抽象解释。
- 如果是开源工具教程：工具名称、GitHub URL、安装条件、复现步骤、验收结果、常见错误。
- 用户的真实业务案例优先；不虚构营业额、合同、曝光、截图。
- 提词器格式可加可选停顿标记，但不要使正文生硬。
- 给出视觉建议，只针对用户实际拥有的素材，不冒充已经拍摄。
