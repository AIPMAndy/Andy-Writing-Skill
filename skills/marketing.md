# 场景：服务推广 / 商业转化文案

主参考外部 `copywriting` 的场景流程（仅适配，不默默安装）。

- 首先确定谁是客户、他为什么现在需要解决、可验证的区别在哪里、能交付什么。
- 根据用户明确的服务定位写出具体价值和动作，禁止收入保证、“必爆”、“包过”等不可支持表述。
- 产品与服务名称、价格、服务时长、交付物和 URL 必须从用户提供的最新可信信息获取。
- 写生活/知识帖时商业内容适度穿插，自然地从方法或案例过渡；若用户只要干货，纯干货优先。
- 页面文案：首屏价值 → 具体受众 → 过程与交付 → 有来源的案例 → FAQ → 下一动作。
- 不能把免费开源产品偷换成必付费服务，不能把咨询意向写成实际成交。
